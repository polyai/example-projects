# Restaurant template

Books, checks, changes and cancels tables for one restaurant site, answers restaurant FAQs, and texts menu and booking-form links.

- **Shape (flat):** one flow per task, each with one advanced step and a short numbered prompt. `check_booking`, `change_booking` and `cancel_reservation` start with an entry function step that checks ID&V and picks the booking. Rules live in tool code (`functions/bookings.py`, `functions/hours.py`, `functions/idnv.py`); tools give the question to ask next, and end with a CALL STATE block.
- **ID&V (lax):** only to find an existing booking - caller ID match, or the number the booking is under plus the name on it (`flows/verify_caller`). A new booking needs none. No caller ID (Studio chat or simulation, an email address) is never treated as a fixture caller.
- **RSN-1 rules:** at most 6 parameters per tool (booking: `update_booking_request` for party/day/time, `update_booking_details` for name/number/note); retry returns name the attempt and say to call the same tool again; a write is confirmed by one short yes-or-no question naming the action and the key details, with no separate readback (≤ 25 words), and `caller_confirmed`/`number_confirmed`/`use_calling_number` take only a clear yes to it ("okay" isn't one); a 'true' in the same turn as the question (the history's length unchanged, used only as a marker) writes nothing and speaks the question again (an utterance, which ends the tool loop); no keypad (`dtmf_config` is Raven 3.5 only).
- **Facts:** variant attributes - `site_name`, `address`, `address_info`, `phone_number`, `opening_hours`, `timezone`, and the `*_info` policies read by topics. Hours and timezone always come from the variant.
- **Switches:** real-time config `settings` - `max_party_size` (8), `cancel_booking_flow_enabled` (true), `transfer_out_of_hours` (true), `csat_enabled` (false), `use_mock_api` (true).
- **Data:** `functions/api_client.py`. Mocked on branch, draft and sandbox; mocked on pre-release and live until `settings.use_mock_api` is false. Mock bookings live in `conv.state`.
- **Fixtures:** John Smith 201-555-0123 (4 people tomorrow 7pm), Jane Doe 212-555-0178 (2 people, day after tomorrow 8pm), Maria Garcia 312-555-0144 (two bookings), Alex Turner 201-555-0177 (none upcoming), 201-555-0199 (no guest).
