# Retail WISMO template

Tells callers where their order is, cancels or re-addresses orders that haven't shipped, texts tracking and store links, and answers store FAQs.

- **Shape (flat):** one flow per task, each with one advanced step and a short numbered prompt. `track_order`, `cancel_order` and `change_address` start with an entry function step that checks ID&V (and picks the order). Rules live in tool code (`functions/orders.py`, `functions/idnv.py`); order tools say what to tell the caller next and end with a CALL STATE block (retry returns end with the call-again line).
- **ID&V (lax):** caller ID match, or the phone number on the account plus the account holder's name (`flows/verify_caller`). Retry limits and the transfer on failure are in `functions/idnv.py`. No order detail is said before verification. No caller number (Studio chat and simulations) means no caller ID: verification asks.
- **Retries:** limits are counted in the tools. Every retry return names the attempt and says to call the same tool again, even with the same answer; the last miss transfers. Write tools, `send_link` and the ID&V number readback (`phone_confirmed`) act only on a clear yes to the tool's short yes-or-no question, which names the action and key value only ("okay" is not a yes; at ID&V an "okay" goes back to `verify_caller` as `phone_confirmed='false'` and is counted), and refuse a yes passed in the same turn as the readback (history length as the marker, never the content). No keypad: `dtmf_config` works on Raven 3.5 only.
- **Orders:** the caller picks an order by item or digits of the order number (matched in code); with several orders and no hint, the agent gives a short update on each. Held orders and store-cancelled orders transfer. Cancelling completes in the agent unless `settings.cancel_order_flow_enabled` is false.
- **Store facts:** all variant attributes (`config/variant_attributes.yaml`), including `opening_hours` and `timezone`, which the out-of-hours check reads from the variant. Blank or unreadable `opening_hours` count as open, and the agent says the hours aren't to hand (topic goes through `get_opening_hours`). Never hardcode a store fact in topics, rules or code.
- **Data:** `functions/api_client.py`. Mocked on branch, draft and sandbox; mocked on pre-release and live until `settings.use_mock_api` is false. Mock changes live in `conv.state`.
- **Fixtures:** John Smith 201-555-0123 (shoes and socks shipped with UPS, ending 7561; backpack processing, ending 1204), Jane Doe 212-555-0178 (sneakers delivered), Maria Garcia 310-555-0142 (split, pickup and on-hold orders), 201-555-0199 (no account).
